Product Summary
PestLedger (aka PCOPro) is a production-grade, ledger-based inventory + request management system for pest control operators.

Core Principles (Non‑negotiable)
- Ledger-only inventory: balances are derived from immutable transactions. Never directly mutate balances.
- Idempotent transactions everywhere: deterministic idempotency keys for all “posting” actions.
- Multi-location support: location scopes like WAREHOUSE, TRUCK:{techId}, etc.
- Auditability over convenience: full traceability beats shortcuts.
- Mobile-first UI, desktop-friendly.
- Role-gated workflows with ADMIN-configurable permissions (eventual).

Tech Stack
- Backend: NestJS + Prisma + PostgreSQL (Docker)
- Frontend: React (Vite) PWA
- DB schema is authoritative via Prisma migrations (but DB state is source of truth when Prisma gets confused)

Prisma & Migration Rules (Critical)
- Use ONLY: prisma migrate deploy (against existing DB)
- NEVER run: prisma migrate dev against an existing DB
- NEVER edit an applied migration
- NEVER delete migration_lock.toml again
- Migration “20260120105720_add_analytics_indexes” is LOCKED + APPLIED
  - If Prisma CLI complains it “cannot find” it: treat DB as truth; use prisma migrate resolve only if necessary.
  - Prefer manual SQL + resolve over resets.
- We will not reset the DB again.

Branch & Merge Policy (Mandatory)
- main = protected, stable
- ALL work on feature/* branches, one feature per branch
- Commit early/often. Do not leave uncommitted Prisma files overnight.
- Merge flow:
  1) git switch feature/xyz
  2) git pull origin main
  3) git push origin feature/xyz
  4) Open PR → review file list (especially prisma/)
  5) Merge via GitHub (fast-forward only)

Git Cleanup (Safe Delete Rules)
- After a PR is merged AND you have updated local main:
  - git switch main
  - git pull origin main
  - git branch -d feature/xyz
  - git push origin --delete feature/xyz
- If branch won’t delete locally: use -D (only if you’re 100% sure it’s merged).
- If it says “branch not found”, you’re either not on the right repo/worktree or the branch name differs.

Known Issues / Bugs (Active)
UI/UX
- Dropdown style inconsistency across pages (Audit vs others). Goal: global dropdown component with built-in search.
- iOS zoom-on-select behavior for dropdowns (not urgent; likely input font-size / viewport handling).
- Audit discrepancy report UX: placement and filter UI feels heavy; consider report-run UX.

Operational/Taxonomy
- Category vs ProductType vs Formulation:
  - Category = business bucket for analytics/rules
  - ProductType = functional intent (bait/IGR/termiticide/etc.)
  - Formulation (granule/dust/aerosol/gel) is future field; do not overload category/type.

Costing (Important)
- defaultCostPerBase must be per base unit.
- Bulk import supports costPerTrackingUnit → defaultCostPerBase = costPerTrackingUnit / trackingToBase.
- For MVP: cost per bottle for Demand; no averaging across case/master-shipper yet.
