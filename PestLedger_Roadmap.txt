PROJECT SUMMARY
PestLedger (aka PCOPro) is a production-grade, ledger-based inventory + request management system for pest control operators.

Primary goals:
- Full auditability of inventory movement
- Mobile-first UX for technicians
- Strong role gating and permissions
- Scalable foundation for ordering, analytics, and compliance

NON-NEGOTIABLE CORE PRINCIPLES
1) Ledger-only inventory
   - Inventory balances are derived from immutable ledger transactions
   - Balances are NEVER directly mutated

2) Idempotent posting everywhere
   - All posting actions must be safely repeatable
   - Deterministic idempotency keys required

3) Multi-location scopes
   - Examples: WAREHOUSE, TRUCK:{techId}, etc.

4) Auditability > convenience
   - Traceability and explainability always win

5) Mobile-first UI
   - Desktop support is secondary

6) Role gating
   - TECH is restricted:
     - No Analytics access
     - Sees "In Stock" only, not numeric balances
   - Other roles see progressively more detail
